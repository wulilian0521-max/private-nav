# 私人导航 · Private Nav

可自行部署的私人网址导航，集中管理常用入口。支持电脑与手机、浏览器配对授权，以及可选的 AI 命名和查找。

## 功能

- 添加、编辑、删除、分类、置顶、关键词搜索，支持 JSON 导入和导出。
- 自适应电脑和手机界面，iPhone 可通过 Safari 添加到主屏幕。
- 一次性配对码授权，最多两个浏览器；配对码 10 分钟有效。
- 添加网址时读取公开网页信息；可配置 AI 生成中文名称、简介和分类。
- 使用自然语言从自己的收藏中查找入口。

## AI 费用与隐私

**本项目不提供共享 API、内置密钥或作者的 API 额度。** AI 只使用部署者在自己服务器上配置的接口、模型和密钥，费用由该接口账户承担。未配置时不会发送 AI 请求，关键词搜索与网址管理仍然可用。

前端请求本站的 `/api/`，AI 密钥由后端从环境变量读取，不发送给浏览器。请勿把真实 `.env`、密钥、数据库、配对码、网址备份或运行日志提交到仓库。

AI 查找会把查询描述、候选收藏的名称、分类和网址发送给部署者配置的模型服务。发送的网址去掉查询参数和片段，收藏备注不发送给模型。AI 命名发送当前网址、公开页面标题、简介与分类。网址路径或用户输入仍可能含私人信息，请根据自己的数据选择可信服务；`store: false` 不能代替服务提供方的隐私政策。

仓库不包含作者的私人收藏、备注、密码、设备授权、真实 API 配置或生产数据库。每个新部署会创建自己的空数据库和配对码，不连接作者的私人网站。源码里的常见网站域名用于通用名称识别，并非作者的收藏列表。

本工具不负责保存目标网站的账号密码；目标网站仍需要各自登录。设备授权依赖浏览器 Cookie，并非硬件锁。数据库未做应用级加密，请保护服务器和备份。

## 本机体验

需要 Python 3.9 或更新版本，仅使用标准库，无需安装 Python 第三方依赖。

下载并解压仓库，在项目文件夹的终端运行：

```sh
python3 app.py serve --open
```

默认仅监听 `127.0.0.1:8765`。在打开的页面输入终端显示的首次配对码。首次启动收藏为空，数据保存在项目下的 `private-data/`，该目录已在 `.gitignore` 中排除。请勿分享配对码。

此方式用于本机体验。电脑和手机跨网络访问请使用自己的 HTTPS 服务器部署，不能仅上传 HTML 到 GitHub Pages。双击 HTML 文件也无法提供完整功能。

## 服务器部署

需要自己的 Linux 服务器、Docker Compose 和指向该服务器的域名。确认 80/443 端口可供本项目使用。

```sh
cp .env.example .env
# 编辑 .env，将 NAV_DOMAIN 改成自己的域名，不包含协议和路径。
chmod 600 .env
docker compose up -d --build
docker compose logs navigation
```

Caddy 将为配置的域名提供 HTTPS。在浏览器打开该域名，输入日志里的首次配对码。日志只应由管理员访问；配对码过期且尚未配对时，可重启 navigation 服务生成新码。

已授权浏览器可以在「设备」中生成另一台浏览器的配对码。网址数据保存在 Docker 命名卷中；不要执行会删除数据卷的 `docker compose down -v`。

已有宿主机反向代理时，可使用 `compose.existing-proxy.yaml`，将现有 HTTPS 网站代理到 `http://127.0.0.1:18765`，保留原始 Host。反向代理若在容器内，需要按实际容器网络配置。请固定使用选定的一套部署文件。

## 可选 AI 配置

Compose 部署在自己的 `.env` 中填写：

```dotenv
NAV_DOMAIN=nav.example.com
NAV_AI_BASE_URL=
NAV_AI_MODEL=
NAV_AI_API_KEY=
```

后三项默认留空。需要 AI 时，填写自己的兼容 Chat Completions 接口地址（包含 `/v1`）、模型名称和密钥。接口需要支持 JSON 对象响应及代码中的生成参数；远程接口使用 HTTPS，HTTP 仅支持后端本机回环地址。更改配置后重新创建 navigation 容器。

直接运行 Python 时请通过进程环境变量传入配置，程序不会自动加载 `.env`。容器内的 `127.0.0.1` 指向容器自身，不能直接套用宿主机的本地接口地址。
